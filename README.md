# New Image Auto Services

One-page site for New Image Auto Services, 7622 Talbert Ave, Huntington Beach, CA.

Plain static HTML/CSS/JS with no build step. It runs on GitHub Pages as is: Settings → Pages → deploy from `main`, root folder.

- `index.html`: content
- `styles.css`: all styling
- `script.js`: the sign's shadows follow the real sun position over the shop, plus open/closed status and today's hours
- `assets/`: storefront photo and social preview image

Preview locally: `python3 -m http.server` and open http://localhost:8000

Possible domain (available): newimagehb.com
